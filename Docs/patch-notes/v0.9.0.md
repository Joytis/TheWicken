# The Witch v0.9.0

## New
- **Blood Anointment** — New Uncommon Skill (1 Energy, Multiplayer only): Choose another player. Their Attacks apply 1 Hex this turn (upgrade: costs 0).
- **Bottle Bombardment** — New Rare Attack (2 Energy, Multiplayer only): Deal 10 damage for each Potion created by ANY player this combat (upgrade: 14).
- **Plague Tide** — New Rare Power (2 Energy, Multiplayer only): ALL players Summon a Rat Familiar (upgrade: Rat Familiar+).

## Reworks
- **Familiars** — Tokens are no longer random. Each familiar now cycles through its cards in order, one per turn, per stack: Owl (Wisdom → Knowledge), Cat (Ferocity → Nimble), Crow (Dark Omen → Shiny), Bear (Hibernate → Mutilate), Rat (Swarm → Rummage), Wolf (Gnash → Pack Tactics).
- **Smolder** — Now: Gain 5 Block, create an Unstable Ember Jar immediately (was: Gain 4 Block, create one at the start of each of the next 2 turns). The Smolder power is gone.
- **Torment** — Now Common. Damage 3 → 5 (upgrade +2 → +3); no longer draws a card.
- **Ritual Sacrifice** — Exhaust 3 → 2 cards, Hex 7 → 6. Upgrade now +1 card and +1 Hex (was +3 Hex).
- **Hidden in Smoke** — Upgrade now reduces cost by 1 (was Innate).
- **Nimble** (Cat token) — Nimble+ now also gains 2 Block.
- **Dark Omen** (Crow token) — Now applies Hex to ALL enemies (was single target).
- **Crystal Bottle** — Healing Potions can no longer be bottled.
- **Wicked Brew** — Creates Fertilizer instead of Flex Potion; Fertilizer removed from Stony Brew's table.
- **Separatory Funnel** — Now the Witch's Ancient Orobas relic (replaces Bottomless Pockets, which is removed).
- **Cozy Nest** — Shop → Rare relic.
- **Wormy's Apple** — Uncommon → Shop relic.
- **Buddy in a Bottle** — Rare → Uncommon potion.

## Changes
- **Bear Familiar** — Cost 1 → 0.
- **Hexblast** — Cost 3 → 2, Damage 8 → 7.
- **Rummage** (Rat token) — Cost 1 → 0.
- **Sprouts** — Upgrade now also +2 Brambles.
- **Weathered Witch Hat** — Upgrade +2 → +3 Block.
- **Brambleburst** — Cost 2 → 3, damage per Bramble 1 → 2.
- **Creeping Vines** — Brambles 7 → 5.
- **Owl Familiar** — Cost 1 → 2.
- **Rat Familiar** — Cost 1 → 2.
- **Bag of Teeth** — Common → Uncommon.

## Other
- **Removed:** Wormy Apple potion; the familiar token potions (Wolf Fang, Bear Fur, Cat Whisker, Crow Talon, Owl Feather, Rat Tail).
- Bottle Barrage has new throw SFX/VFX.
- Custom Yummy Cookie icon for the Witch.
- New card art: Bewitching Grin, Read the Bones, and more.
