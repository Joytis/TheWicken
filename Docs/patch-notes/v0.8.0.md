# The Witch v0.8.0

## New
- **Impale** — New Uncommon Attack (2 Energy): Deal 12 damage. Brambles deal double damage this turn (upgrade: +3 damage).
- **Pack Tactics** — New Wolf familiar token: Gain 2 Strength this turn (upgraded: 4).
- **Ash** — New Status card (Unplayable, Ethereal), left behind by fire cards.

## Reworks
- **Wolf Familiar** — Now grants a random token each turn: Gnash or Pack Tactics (was: always Gnash).
- **Bonfire** — Now adds 2 Ash into your Discard Pile. Ash can't be chosen for the Exhaust.
- **Tinder** — Now adds an Ash into your Discard Pile. Ash can't be used as kindling.
- **Bottomless Cauldron** — Upgrade now reduces cost by 1 (was Innate).
- **Gather Herbs** — Removed from the pool.

## Nerfs
- **Hide in a Bush** — Block 7 → 6.
- **Incant** — Block 8 → 7.
- **Smolder** — Block 5 → 4.
- **Wax and Wane** — Block 8 → 7.
- **Toil and Trouble** — Damage 5 → 4.
- **Volatile Vapors** — Damage per potion 5 → 4 (upgrade +3 → +2).
- **Weathered Witch Hat** — Upgrade +3 → +2 Block.
- **Deep Roots** — Upgrade +2 → +1.
- **Dark Omen** (Crow token) — Hex 2 → 1.
- **Ember Jar** — Damage 5 → 4.
- **Noxious Brew** — Damage 10 → 8.
- **Treasure potions** — Damage: small 5 → 4, big 7 → 6.
- **Witchcraft** — Created Potions are now Unstable.
- **Prices Paid** — Created Noxious Brews are now Unstable.

## Other
- Fixed: Gnash pack damage now counts each played Gnash's own bonus, so mixed normal/upgraded Gnashes add up correctly.
- Fixed: Cat Familiar+ hover tips no longer break.
- New card art (PLACEHOLDER): Impale, Pack Tactics, Ash.
- New potion art: Cursed Bottle, Ominous Flask, Prickly Vial, Puff of Smoke.
